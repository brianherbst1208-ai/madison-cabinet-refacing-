# Madison Cabinet Refacing

Static local-service site for Madison Cabinet Refacing — Madison, WI and Dane County.

- **Live domain:** madisoncabinetrefacing.com (GitHub Pages, `main` / root)
- **Pages:** homepage, About, Contact, 5 service pages, 6 city landing pages
- **Assets:** `/images/` (uploaded via the GitHub web UI — binaries cannot be committed through the API)
